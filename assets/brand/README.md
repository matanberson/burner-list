# Burner List brand assets

- `burner-list-logo.svg`: standalone app mark on its cream tile.
- `burner-list-wordmark.svg`: transparent horizontal lockup for light backgrounds; charcoal mark and lettering.
- `burner-list-wordmark-dark.svg`: transparent horizontal lockup for dark backgrounds; cream mark and lettering.

The ember red and amber burner circles stay unchanged in both wordmark variants. Keep the SVG aspect ratio intact and do not recolor the individual shapes in feature code.
