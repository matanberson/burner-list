One zone of the Burner List: an uppercase label, an optional project-name line (Front/Back Burner only — Kitchen Sink has none), a stack of TaskRows, and an "Add task" affordance. Zones compose into the two-column paper layout — never restructure that hierarchy.

<ZonePanel label="Front Burner" placeholder="Your #1 priority" tasks={[{text:'Ship v1', done:false}]} />
